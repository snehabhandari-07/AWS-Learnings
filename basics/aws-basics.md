# AWS - Amazon Web Services

It's a company that provides cloud services.

## So, how do they have these services?

- Because they actually own land and have set up infrastructure.  
- They have data centers on this land they purchased.  
- So when we talk about using AWS services, we are actually using their servers and storage which exist physically.  
- Data centers are large spaces dedicated to keep or host resources that you can use.  
- AWS has a global infrastructure — meaning data centers are available across the world.  
- That is the reason why, even if millions and billions of people use it, it never runs out.

## In AWS, we have 2 key terms at the start:

- **AZ** — Availability Zone  
- **Region**

**AZ** is a space or land with data centers.  
**Region** is a place which has more than 3 AZs.

***India has 2 regions, meaning a total of 6 AZs.***

## Why use AWS?

It provides three major service models:  
- **IaaS** (Infrastructure as a Service) — user needs to manage everything.  
- **PaaS** (Platform as a Service) — AWS manages everything, user needs to deploy things.  
- **SaaS** (Software as a Service) — used as a service by the end user.

### Three major service models:

- **IaaS (Infrastructure as a Service)**  
  You get basic computing resources like servers, storage, and networks, but you manage everything else (OS, apps, data).  
  *Example:* Using EC2 (virtual servers) where you install and manage your own software.

- **PaaS (Platform as a Service)**  
  AWS manages the infrastructure and platform, so you only focus on deploying and managing your applications.  

- **SaaS (Software as a Service)**  
  The software is fully managed by AWS or a provider, and you just use the application.  
  *Example:* Amazon WorkMail (email service), or using third-party apps hosted on AWS.

## How can we use AWS?

- Via Console  
- Via CLI (Command Line Interface)  
- Via SDK (Software Development Kit)
